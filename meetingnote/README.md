# 필수 설정 가이드

## Info.plist에 추가해야 할 권한

프로젝트가 제대로 작동하려면 `Info.plist` 파일에 다음 권한 설명을 추가해야 합니다:

1. Xcode에서 프로젝트 네비게이터에서 `Info.plist` 파일을 선택합니다
2. 파일에 마우스 오른쪽 버튼을 클릭하고 "Open As" > "Source Code"를 선택합니다
3. `<dict>` 태그 안에 다음 내용을 추가합니다:

```xml
<key>NSMicrophoneUsageDescription</key>
<string>회의 내용을 녹음하기 위해 마이크 접근 권한이 필요합니다.</string>

<key>NSSpeechRecognitionUsageDescription</key>
<string>녹음된 음성을 텍스트로 변환하기 위해 음성 인식 권한이 필요합니다.</string>
```

## iCloud 설정 (옵션)

데이터를 iCloud에 자동으로 백업하려면:

1. Xcode에서 프로젝트를 선택합니다
2. "Signing & Capabilities" 탭으로 이동합니다
3. "+ Capability" 버튼을 클릭합니다
4. "iCloud"를 검색하고 추가합니다
5. "CloudKit" 체크박스를 선택합니다
6. "+ Add Container" 버튼을 클릭하여 새 컨테이너를 생성합니다

## Apple Intelligence 사용을 위한 최소 요구사항

Foundation Models (Apple의 온디바이스 LLM)를 사용하려면:

- iOS 18.2 이상
- Apple Intelligence를 지원하는 기기 (iPhone 15 Pro 이상, M1 이상의 iPad/Mac)
- 설정 > Apple Intelligence에서 Apple Intelligence 활성화

## 빌드 및 실행

1. 실제 기기에서 테스트하는 것을 권장합니다 (시뮬레이터에서는 마이크 및 음성 인식이 제한적입니다)
2. 앱을 처음 실행하면 마이크 및 음성 인식 권한을 요청합니다
3. "허용"을 눌러 권한을 부여합니다

## 주요 기능

### 1. 실시간 녹음 및 전사
- "녹음" 탭에서 마이크 버튼을 눌러 녹음 시작
- 실시간으로 음성이 텍스트로 변환됩니다
- 다시 버튼을 눌러 녹음 종료

### 2. 마크다운 편집
- 녹음 종료 후 자동으로 편집 화면으로 이동
- 툴바를 사용하여 텍스트 스타일 지정 (굵게, 기울임, 밑줄 등)
- 헤더, 리스트, 색상 등 다양한 마크다운 요소 추가 가능

### 3. AI 텍스트 정리
- 편집 화면 상단의 별 아이콘을 탭
- 다양한 처리 옵션:
  - **요약**: 회의 내용을 간결하게 요약
  - **회의록 작성**: 공식 회의록 형식으로 변환
  - **액션 아이템 추출**: 할 일 목록 자동 생성
  - **커스텀 프롬프트**: 원하는 형태로 텍스트 변환

### 4. 로컬 데이터 관리
- 모든 녹음 파일과 텍스트는 기기에 로컬로 저장
- SwiftData를 사용하여 자동으로 데이터 관리
- iCloud를 활성화하면 자동으로 동기화

## 문제 해결

### "음성 인식을 사용할 수 없습니다" 오류
- 설정 > 개인정보 보호 > 음성 인식에서 앱에 대한 권한 확인
- 인터넷 연결 확인 (처음 사용 시 필요할 수 있음)

### "LLM 모델을 사용할 수 없습니다" 오류
- 기기가 Apple Intelligence를 지원하는지 확인
- 설정 > Apple Intelligence에서 기능이 활성화되어 있는지 확인
- 모델이 다운로드 중일 수 있으니 잠시 후 다시 시도

### 녹음 파일이 저장되지 않음
- 기기 저장 공간 확인
- 앱을 재시작해보세요
