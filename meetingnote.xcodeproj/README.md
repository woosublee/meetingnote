# AI 미팅 노트

실시간 음성 전사와 AI 기반 요약 기능을 제공하는 미팅 녹음 앱입니다.

## 주요 기능

- 🎙️ **실시간 녹음 및 전사** - 회의 중 자동으로 음성을 텍스트로 변환
- 📝 **마크다운 편집** - 전사된 내용을 마크다운으로 편집
- 🤖 **AI 요약** (개발 예정) - LLM을 활용한 자동 요약 및 핵심 내용 추출
- 📂 **노트 관리** - 모든 미팅 노트를 한 곳에서 관리
- 🔍 **검색** - 노트 내용 전체 검색
- 🔊 **시스템 오디오 캡처** (개발 중) - 온라인 미팅 음성 녹음 기능 준비 중

## 시스템 요구사항

- macOS 14.0 이상
- Xcode 15.0 이상
- Swift 5.9 이상

## 권한 설정

앱이 다음 권한을 요청합니다:

- **마이크 접근** - 미팅 녹음을 위해 필요
- **음성 인식** - 실시간 전사를 위해 필요
- **화면 녹화** (macOS, 선택사항) - 시스템 오디오 캡처 기능 개발 시 필요 (현재 개발 중)

## 사용 방법

1. **녹음 시작**
   - "미팅" 탭에서 "기록하기" 버튼 클릭
   - 미팅 제목 입력
   - "녹음 시작" 버튼 클릭

2. **실시간 전사**
   - 녹음 중 자동으로 음성이 텍스트로 변환됩니다
   - 전사된 내용이 실시간으로 표시됩니다

3. **노트 저장 및 편집**
   - 녹음 중지 후 자동으로 저장
   - "노트" 탭에서 저장된 노트 확인
   - 노트를 클릭하여 마크다운 편집기에서 수정
